# aespa_desktop_pet

略略 macOS 桌宠的**私有工程备份与演示**。

## 文件

- `略略-源码与演示-私人交付包.zip`：完整整理包。解压后的 `repository/` 包含 Swift 源码、构建脚本、浏览器扩展和验证记录；`NOT_FOR_PUBLIC_UPLOAD/` 分开保存四套皮肤与视频。
- `略略动态快剪版.mp4`：38 秒真实界面快剪，含用户指定配乐。部分联网和隐私功能仅以离线入口演示，未执行真实聊天发送或重启。
- `demo-muted.mp4`：约 28 秒静音版本，已移除官网照片与榜单画面；仍包含角色素材。

## 使用

下载 ZIP 后完整解压，先读根目录 `先读我.md`，再读 `repository/README.md`。构建需 Apple Silicon Mac、较新 macOS SDK 和 Xcode Command Line Tools。构建步骤为 `bash prepare-assets.sh`、`bash build.sh`。

本包基于 v23，已做静态扫描与脚本/归档检查。整理时 Mac 离线，**清理后的源码包尚未重新在 Mac 编译、签名或运行自测**。未包含 API 密钥、账号密码、个人公告、听歌历史、用户偏好或运行缓存。

## 保持私有

这里没有授予开源许可。音乐、角色和官网图片的公开传播许可未核实，**不要直接改为公共仓库或公开转载这些附件**。静音版本也不代表全部素材权利已确认。包内 `.gitignore` 只防常规误提交，不会改变已上传附件的可见性或许可。
